# Ghost Gauge — site

The public pages for the Ghost Gauge iPhone and iPad app: the App Store support
and privacy URLs, plus a short overview.

- [ghost-gauge-app](https://kmhndi.github.io/ghost-gauge-app/) — overview
- [support.html](https://kmhndi.github.io/ghost-gauge-app/support.html) — App Store support URL
- [privacy.html](https://kmhndi.github.io/ghost-gauge-app/privacy.html) — App Store privacy URL

Served by GitHub Pages from `main` at the repository root. `.nojekyll` is there
on purpose: Jekyll skips files whose names begin with an underscore, which would
drop `_style.css` and leave every page unstyled.

These files are copies. They are maintained in the project repository under
`docs/`, and changes are made there first.
