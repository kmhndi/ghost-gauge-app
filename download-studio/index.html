Getting started

  1. Install it

    Mac: open the file you downloaded and drag Ghost Studio into Applications.

    Windows: run the installer. If Windows shows a blue “Windows protected your PC” box, click More info, then Run anyway.

  2. Request a licence

    Ghost Studio opens on “This laptop needs a licence”. Type your Garage name and Phone number, then click Request a licence.

    It sends only this laptop’s code and its name.

  3. Wait for approval

    Studio shows “Pending approval from Ghost Electronics”. Once we approve, it opens by itself, ready to use.

    You can close it meanwhile: the request stays.

No internet on that laptop?

Under No internet on this laptop? click Copy the request and send it to us on WhatsApp or by email. Open the licence file we send back with Open the licence…, or double-click it.

البدء

  1. ثبّته

    Mac: افتح الملف الذي نزّلته واسحب Ghost Studio إلى مجلد التطبيقات.

    Windows: شغّل المثبّت. إذا ظهر مربع أزرق «Windows protected your PC» فانقر More info ثم Run anyway.

  2. اطلب ترخيصًا

    يفتح Ghost Studio على صفحة تطلب ترخيصًا لهذا الجهاز. اكتب اسم الورشة ورقم الهاتف، ثم انقر طلب ترخيص.

    لا يُرسل إلا رمز هذا الجهاز واسمه.

  3. انتظر الموافقة

    يعرض Studio «بانتظار موافقة Ghost Electronics». بعد موافقتنا يُفتح تلقائيًا جاهزًا للاستخدام.

    يمكنك إغلاقه في الأثناء، فالطلب يبقى.

لا يوجد إنترنت على ذلك الجهاز؟

تحت لا يوجد إنترنت على هذا الجهاز؟ انقر نسخ الطلب وأرسله إلينا عبر واتساب أو البريد الإلكتروني. افتح ملف الترخيص الذي نرسله إليك بزر فتح الترخيص… أو انقر عليه مرتين.
